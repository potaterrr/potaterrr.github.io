Overview

A small, deliberately boring signals pipeline: one strategy, one schedule, one JSON payload. It exists to keep the downstream automation fed, not to predict the market.

How it works

  • Fetches roughly 400 days of daily closes through yfinance (50/200-day defaults)
  • Computes a simple moving-average crossover and emits BUY, SELL or HOLD
  • Dispatches the result as JSON to a Make.com webhook
  • Runs on GitHub Actions every weekday at 21:00 UTC
  • Configurable through environment variables: symbol, SMA windows, webhook URL
  • Forex pairs like USD/PHP are normalized automatically to yfinance format
