A wholesome micro-MMO in a single HTML file. The ads took the beach; the locals kept the kettle on.

Overview

AdBlock Island is a small, wholesome micro-MMO about cleaning up a beach that ads have overrun. You wash ashore with a broom and a class, and the islanders save you a spot by the fire.

It is one self-contained HTML file: no build step, no CDN, no images, no fonts, no backend, no accounts, no trackers. The island is drawn with Canvas 2D; the ocean, lo-fi chords and sound effects are synthesized with Web Audio.

What's in the beta

  • Seven classes with their own silhouettes, gear, projectiles and hit behaviour
  • The wave ladder, medals, items, the Algorithm boss and kindness notes
  • Same-keyboard co-op for a second player
  • Title-screen build tag and patch notes that always agree
  • Runs from a static host, from the release zip, or straight from file://

Honest limits

Co-op is local, not networked. Online multiplayer, accounts and cross-device saves, moderated chat, parties, quests, trading and anti-cheat all need a backend — a single static HTML file cannot provide them.

Versions count from zero while the game is in beta, so every release is 0.x. The current build is v0.6.7 beta.
