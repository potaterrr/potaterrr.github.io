job-scrapper

A Python scraper that watches OnlineJobs.ph and posts one Discord embed per job.

Overview

Job boards reward the first reply. A scraper that checks every ten minutes gets blocked; one that checks once a day is too late.

job-scrapper searches OnlineJobs.ph on a four-hour cadence, keeps the freshest listing per keyword, and posts one rich Discord embed per job so the channel stays readable.

How it works

  • Searches each category's keywords with a randomized 5–12 second pause between requests
  • Parses every result card and sorts by the exact posting timestamp
  • Keeps the top listing per keyword, dedupes across keywords, caps per category
  • Visits each listing for the full description and splits out the "How to Apply" section
  • Summarizes each job with Gemini (falling back to raw fields if the API fails)
  • Dedupes by URL through seen_jobs.json so repeat runs stay quiet

Notes

It started as a Make.com webhook pipeline and moved fully into GitHub Actions: scrape, summarize, post — no second platform in the loop.
