Overview

A small proof that webhooks beat polling: git push fires a GitHub webhook, Make catches it instantly, and a digest lands on a Facebook Page seconds later.

One post per push lists every commit message, so the page reads like a changelog rather than a stream of noise.

Architecture

  • GitHub push webhook → Make custom webhook → Facebook Pages post
  • About 2 operations per push — even ten pushes a day stays well inside 1,000 ops/month
  • No polling, no delay
  • Ships with a sanitized scenario blueprint and a step-by-step setup guide
