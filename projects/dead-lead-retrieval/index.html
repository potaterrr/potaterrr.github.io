Overview

A dormant list is not a dead list. Most of it is people who got busy, changed priorities, or never got a second reply — and manual follow-up is the first thing to slip when the week gets loud.

This pipeline resurrects those leads with personalized check-in emails that a human approves, and keeps the status honest in ClickUp.

The loop

  • Pull the dormant leads and their original context
  • An LLM drafts a short, specific check-in — never a generic blast
  • The email is filed as a Gmail draft for review
  • A booking link is added so a reply turns into a call
  • ClickUp tracks each lead through the review lifecycle

Guardrails

  • AI drafts, a human approves — nothing sends itself
  • Anti-hallucination rules: the only link in any email is mine
  • Original context is passed to the model so the note is relevant
  • Every action is visible in the CRM, not buried in a mailbox
