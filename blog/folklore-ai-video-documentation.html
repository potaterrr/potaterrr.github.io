Folklore AI Video Generator Documentation

August 27, 2026 Documentation

I've been working on a pair of Make.com scenarios designed to automate folklore content creation: one that researches and queues folklore topics, and another that generates AI-powered videos from those topics and shares them across social platforms.

Project Overview

The money-generator project contains documentation for two interconnected Make.com scenarios:

  • Folklore: Research & Queue (Weekly) - Scenario ID: 6067309
  • Folklore: Generate & Publish - Scenario ID: 6067291

Status: Active and functioning correctly

Last Execution: Successful

Schedule: Weekly on Mondays at 9:00 AM

Function: Uses Gemini AI to generate 5 unique folklore topics and adds them to Google Sheets

Modules Used: gemini-ai:createACompletionGeminiPro, google-sheets:addMultipleRows

⚠️ Folklore: Generate & Publish

Status: Active but limited by API quotas

Last Execution: Failed due to quota limits

Schedule: On-demand

Issue: Google Gemini API free tier quota exhausted for video generation

Error: [429] You exceeded your current quota

Root Cause Analysis

The failure is not due to a flaw in the scenario design, but rather external API limitations:

  • Google's free tier for Gemini API (especially Veo video generation) is extremely limited
  • Video generation models typically have near-zero free tier allocations
  • The scenario makes multiple API calls per execution (script generation + video generation)
  • Make.com's free tier limits (1,000 operations/month) are not the bottleneck here

Recommendations for Free Operation

To achieve an "absolutely free" workflow, consider these alternatives:

  1. Modify to Text-Only: Keep the research scenario, modify generate/publish to generate and share folklore scripts only (no video)
  2. Alternative APIs: Research truly free video generation services like Hugging Face inference APIs
  3. Batch Processing: Process only 1 topic per week instead of all queued topics
  4. Different Providers: Check if Make.com offers other AI providers with better free tiers

Technical Details

The scenarios use these key technologies:

  • Make.com: Workflow automation platform
  • Google Gemini AI: For folklore topic research and script generation
  • Google Sheets: As a queue/storage system for folklore topics
  • Facebook Pages: For video sharing (when functional)
  • Telegram: For notifications and content delivery

Access the Documentation

Full technical documentation with scenario blueprints is available in the money-generator repository.

This project represents an exploration into AI-powered content automation, highlighting both the possibilities and limitations of current free-tier AI services for video generation workflows.
